# DataCam
School exhibition project, OpenCV python Face detection/database runner + LIVE WEBAPP Local hosting

# How to Run (Single Command)
Close all terminals. Run ONLY:

1) cd "C:\Nerd\AI EXB"
2) python server.py

-----

## You'll see:

- Console output showing WebSocket and Flask startup
- OpenCV window titled "Face Detection - Server" with live feed
- Browser at http://localhost:5000 showing the same stream
To stop: Press q in the OpenCV window OR Ctrl+C in terminal.
